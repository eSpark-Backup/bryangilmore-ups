# Uninterruptible Power Supply
#### Client Name: Bryan Gilmore

## Project Description
The project requires designing a **U**ninterruptible **P**ower **S**upply in a small form factor with the following features: 
- Compatible with battery [link here](https://www.globalsources.com/Lithium-ion/Lithium-Battery-1176814500p.htm?source=Search_Product_to_PP#ProductCer)
- A surge protector (if possible)
- When the UPS is unplugged from the wall or if the power goes out, the UPS will use battery power instead of outlet power
- A status light ( low battery, charging, and fully charged).
- Board Dimensions preferred to be around 6 x 3 to 6 x 4 inches, and all parts used for the board to still be in production if possible.
- Output Voltage: 12V DC
- Output Current: 10A for 120W
- Frequency Requirement (Input Side): 60Hz
- Output Type: Direct DC Output

#### Note: JLCPCB / LCSC based design will be great
